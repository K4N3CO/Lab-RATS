# Lab-RATS Tactical C2 Server

This is the Node.js backend for the Lab-RATS project. It provides a centralized dashboard for device management and a secure vault for exfiltrated data.

## Features
- **Real-time Fleet Tracking**: Monitoring battery, network, and IP status.
- **Glass-Morphism UI**: Tactical Orbitron-themed dashboard.
- **Auto-Exfiltration**: Receives and stores recordings from target devices.
- **Secure P2P Bridge**: Clickable direct links for remote control.
